# v0.2.0 calibration release evidence

Tested against the checksum-pinned OrcaSlicer 2.4.2 AppImage and source commit `8500fcdccaa10b5099ac20d252af3a7c560046f1`. No printer commands were sent.

## Contract

Calibration capability version is `3`. LayerCove and this sidecar must upgrade together. Temperature bounds are multiples of 5 within 5..350 °C, with increment 5. The bundled model is 700 mm tall, with 70 labelled 10 mm blocks descending from 350 to 5.

Flow rate requires `flow_pattern` and `baseline`, without range fields. Other steps require all range fields and reject `flow_pattern`. Patterns are `yolo`, `yolo_perfectionist`, `pass1`, and `pass2`. See README for modifier formulas and tower heights.

Native mesh height and printable height are enforced. PA's maximum of 2 also applies to the final per-height value. Plater's height formulas can produce a final-layer value above `highest`.

## Checks

1. `cargo fmt --all --check`, `cargo clippy --all-targets -- -D warnings`, and `cargo test` passed with Rust 1.97.1.
2. All four resource-dependent integration tests passed separately with the pinned CLI and resources. They check native object names and counts, cut heights and cut faces, flow modifiers and ratios, scaling, and settings.
3. `CONTAINER_ENGINE=podman python3 tests/container/test_runtime.py localhost/orca-native:dev` passed. It covers all five steps and all four flow patterns on both providers, real artifacts and metadata, MD5 after rewriting, progress, UID 10001, read-only root, dropped capabilities, and no new privileges.
4. Pinned source tests and repeated schema exports passed during image builds. Two independent Rust builder stages produced process schema SHA-256 `400a48147c06ed728ac6c8a2e11e61bfbfc94379fcf66025be62e1538e771854`.
5. The native-model assertion fails against the prior v0.1.9 image with `AssertionError: temperature_tower`.
6. Local container contract checks reached the Ruby workflow validator, which could not run because Ruby is absent on this host. CI runs that validator.

Artifact checks establish slicing behavior, not physical print quality. Native time and filament estimates precede G-code postprocessing.
