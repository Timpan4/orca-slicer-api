# v0.2.1 calibration fixes

Calibration capability remains `3`. Temperature bounds remain multiples of 5 within 5..350 °C. LayerCove PR 398 can retain that contract. The pinned Orca source remains `8500fcdccaa10b5099ac20d252af3a7c560046f1`; slicing uses the checksum-pinned 2.4.2 AppImage.

## Changes

1. Volumetric outer walls use the profile's first-layer speed and Orca's slowdown ramp. Only positive relative extrusion moves receive calibration feedrates; wipes keep their original feedrates. The Klipper gate includes a custom profile that exercises the ramp.
2. Draco export uses the configured CLI, shared slicer timeout and process-group cleanup.
3. Mesh cuts weld at STL precision, discard repeated vertices and zero-area faces, derive contours from retained boundary edges, and preserve collinear cap vertices and holes. Temperature cuts use Plater's 0.0001 mm offset.
4. Flow models apply build-item affine transforms and reject malformed, non-finite or singular matrices.
5. Volumetric beds use the shared bounds parser. Malformed or unusable beds return HTTP 400 before export.
6. Image builds run the four ignored calibration integration tests and the serialized-mesh regression test with the final runtime's CLI and libraries.

## Regression evidence

The tests were run against the original `f9910c94dabd3517de394e87415eec5f5d247b57` code in a separate directory. The vertex-plane cube cut fails with a degenerate triangle, the build-transform fixture starts at X=0 instead of -93, the wipe check detects a changed feedrate, and the unusable-bed request fails to return a bad-request error. The per-layer container check fails against the v0.2.0 image on the first layer: 1620 mm/min instead of the configured 3000 mm/min.

The serialized-mesh checks cover temperature 200..210, retraction at 3.4 mm and volumetric at 14.1 mm. Every triangle has nonzero area, and every undirected edge has exactly two faces with opposite winding after writing and reading STL. Synthetic tests also cover a tilted cube cut through existing vertices and an annular cap on a hollow cube.

Artifact checks establish slicing behavior, not physical print quality. Native time and filament estimates precede G-code postprocessing. No printer commands were sent. The PR remains unmerged, wall-e-infra is unchanged, and the existing v0.2.0 tag is preserved.
